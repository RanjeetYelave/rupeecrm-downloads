Step-by-Step Instructions

Getting Started in Minutes

Follow the verified installation guide for your desktop operating system.

1

Download Installer

Click the Download for Windows button above to download the latest RupeeCRM-Setup-x64.exe package.

2

Run Setup Package

Double-click the downloaded executable. If prompted by Windows UAC, click "Yes" to grant installation permissions.

3

Follow Setup Wizard

Accept the installation destination directory. The wizard will automatically deploy all required desktop runtime components.

4

Launch & Register

Launch RupeeCRM from your desktop shortcut or Start Menu. Set up your primary firm name and begin billing immediately.

Windows SmartScreen Note: Because RupeeCRM is distributed directly via GitHub Releases without an expensive commercial EV certificate, Windows Defender SmartScreen may display an alert. Click "More info" and then select "Run anyway" to proceed.
1

Download Apple Silicon DMG

Download the official RupeeCRM-arm64.dmg disk image designed for M1/M2/M3/M4 Macs.

2

Mount Disk Image

Double-click the downloaded .dmg file in Finder to open the RupeeCRM installer window.

3

Drag to Applications

Drag the RupeeCRM.app icon into your macOS /Applications folder shortcut.

4

Launch Application

Open RupeeCRM from your Applications folder, Launchpad, or Spotlight search (Cmd + Space).

macOS Gatekeeper First-Launch Note: When opening for the first time, if macOS states the app is from an unidentified developer, open System Settings → Privacy & Security, scroll down to the Security section, and click "Open Anyway".
Specifications

System Requirements

RupeeCRM is lightweight, optimized for multi-core performance, and self-contained.

Windows Specifications

  • Operating System Windows 10, 11 (64-bit)
  • Processor 1.6 GHz Intel / AMD Dual Core
  • Memory (RAM) 4 GB minimum (8 GB recommended)
  • Available Disk Space 1 GB free storage
  • Java Runtime Bundled internally (No separate JRE needed)

macOS Specifications

  • Operating System macOS 12.0 Monterey or higher
  • Processor Apple Silicon M1 / M2 / M3 / M4 (or Rosetta 2)
  • Memory (RAM) 4 GB minimum (8 GB recommended)
  • Available Disk Space 1.2 GB free storage
  • Display Resolution 1280 x 800 minimum
